# LightningChart MAUI Examples

Each example's README explains how to build and run it locally.

Learn more: [LightningChart MAUI documentation](https://lightningchart.com/lc-la/docs/clients/maui)

- [Heatmaps](./MauiHeatmaps/) — Synthetic machine measurements using default, opposite, parallel, and stacked axes.

- [Multiple axes](./MauiMultipleAxes/) — Static and scrolling heatmaps with value-based coloring.

- [Patient vital signs](./MauiVitalSigns/) — Historical loading and real-time streaming displaying patient vital signs.
