LightningChart Language Agnostic is an ecosystem with a singular purpose - bringing LightningCharts' high performance data visualization libraries available to all developers, regardless of what kind of framework, platform or programming language you use.

LightningChart Ltd. is a Finnish company founded in 2007 that creates the **WORLD'S FASTEST** charting libraries for all kinds of software industries requiring snappy, robust charts that don't crumble under pressure.
For more information on the company, please refer to [lightningchart.com](https://lightningchart.com/)

**LC LA** is a sophisticated open-source wrapper system based on [LightningChart JS](https://lightningchart.com/js-charts/), a web library with incredible range of features, customizability and [performance](https://lightningchart.com/js-charts/performance/).
