Data is organized into datasets containing named numeric columns. Series select columns for their X and Y values. Multiple series can use the same dataset.

Dataset and column IDs connect the dataset definition, series bindings, and supplied data. Use matching IDs across these operations.


## Adding datasets

A dataset requires an ID and column definitions. Its maximum sample count is optional.

Dataset IDs must be unique within their owning context. Charts sharing a context can use the same dataset.

### At chart creation

Include datasets in the chart configuration. Series in that configuration can reference them immediately.

The following example creates a dataset with two columns.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

After rendering the chart container and initializing the context:

```csharp
var chart = await context.CreateChartAsync(new XYChartConfig
{
    ContainerId = "signal-chart",
    DataSets =
    [
        new DataSetConfig
        {
            Id = "dataset",
            MaxSampleCount = 1_000_000,
            Columns =
            [
                new DataSetColumnConfig { Id = "x" },
                new DataSetColumnConfig { Id = "y" },
            ],
        },
    ],
});
```

## Column patterns

For ordered data, declare a pattern separately for each column:

- **Progressive** indicates increasing values.
- **Regressive** indicates decreasing values.
- Leave the pattern unspecified for unordered values.

For example, configure a column containing increasing values as follows:

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

```csharp
new DataSetColumnConfig
{
    Id = "x",
    DataPattern = DataPattern.Progressive,
}
```

</TabItem>
<TabItem value="maui" label="MAUI">

```csharp
new DataSetColumnConfig
{
    Id = "x",
    DataPattern = DataPattern.Progressive,
}
```

</TabItem>
<TabItem value="uno" label="Uno">

```csharp

{
    Id = "x",
    DataPattern = DataPattern.Progressive,
}
```

</TabItem>
<TabItem value="flutter" label="Flutter">

```dart

  id: 'x',
  dataPattern: DataPattern.progressive,

```

</TabItem>
</Tabs>

Column definitions cannot be edited after dataset creation. To use a different set of columns, create a new dataset and update the relevant series bindings.


## Loading data

Replace a dataset's samples when loading a historical recording or a new selection of data.

Supply an array for every configured column. Corresponding array indices represent the same sample.

The following loads the dataset created above. Obtain the arrays from your application's file, service, or API workflow.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

Here, `xValues` and `yValues` are `double[]` arrays:

```csharp
chart.SetData(new SetDataOptions
{
    DataSetId = "dataset",
    Columns = new Dictionary<string, double[]>
    {
        ["x"] = xValues,
        ["y"] = yValues,
    },
});
```

</TabItem>
<TabItem value="maui" label="MAUI">

All series bound to the dataset display the replaced samples. Their configurations remain unchanged.


## Appending data

Append incoming batches to retain existing samples and add new ones. Supply every configured column in each batch.

Historical loading and streaming use the same dataset definition. A chart can load a recording and continue with incoming samples.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

Call this for each received batch. Here, `batchX` and `batchY` are `double[]` arrays:

```csharp
chart.AppendData(new AppendDataOptions

    DataSetId = "dataset",
    Columns = new Dictionary<string, double[]>
    {
        ["x"] = batchX,
```

## Data cleaning / maximum memory use

The maximum sample count controls how many samples a dataset retains. When appending would exceed the limit, the oldest samples are discarded first.

Set the limit when creating the dataset. If omitted, it is 2,000,000 samples. To increase the limit later, select the dataset by its ID in a chart update.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

```csharp
chart.Update(new UpdateXYChartConfig
{
    DataSets =
    [
        new UpdateDataSetConfig
        {
            Id = "dataset",
            MaxSampleCount = 2_000_000,
```

## Removing datasets

Remove a dataset by its ID. Removal is rejected while any series in the owning context still uses the dataset. Rebind or remove those series first, or include their binding updates or removal requests in the same chart update.

## Sharing datasets

Series can share a dataset while selecting different columns or axes. Data operations affect the dataset, so every series bound to it sees the changes.

Where charts share a context, supply data once through that context rather than sending a separate copy for each chart.

See [LCLA Context](./context) for context ownership and sharing.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

Datasets can also be created directly through the shared context:

```csharp
context.ConfigureDataSets(
[
    new DataSetConfig
    {
        Id = "shared-dataset",
        Columns =
        [
            new DataSetColumnConfig { Id = "x" },
            new DataSetColumnConfig { Id = "y" },
        ],
    },
]);
```

Charts created through that context can reference this dataset. The method also accepts `UpdateDataSetConfig` to increase retention or remove an unused dataset.

Data can be supplied through `context.SetData()`, `context.AppendData()`, and `context.ClearData()` using the same options as the chart methods.

</TabItem>
<TabItem value="maui" label="MAUI">

Data can be supplied through `context.SetData()`, `context.AppendData()`, and `context.ClearData()` using the same options as the chart methods.
