LightningChart LA intentionally concentrates on a focused subset of LightningChart JS capabilities: high-performance, multi-channel XY visualization. This keeps the API small while covering the historical and real-time workloads that matter most in measurement, monitoring, and analysis applications.

It is designed for massive historical recordings — often millions of samples per signal — and real-time views of hundreds of signals at high data rates.

The system is based on LCJS, which supports an incredible number of different features.
Depending on actual proven demand, more of these features will be ported over to LightningChart LA.
