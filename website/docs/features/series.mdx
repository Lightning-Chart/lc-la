A series displays data from a dataset by selecting columns for its X and Y values. Multiple series can share the same dataset and columns.

Each series requires a unique ID, a dataset ID, and its X and Y column bindings. Its display name and color are optional.

## Series types

Choose the configuration class for the visualization you need:

- `LineSeriesConfig` displays a line.
- `ScatterSeriesConfig` displays scatter points.
- `LineScatterSeriesConfig` displays a line with scatter points.

## Adding series

### At chart creation

Add series to the chart's series list. Define their datasets in the same chart configuration or create the datasets beforehand.

The example below defines a dataset with two columns and adds a line series.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

After rendering the chart container and initializing the context:

```csharp
var chart = await context.CreateChartAsync(new XYChartConfig
{
    ContainerId = "signal-chart",
    DataSets =
    [
        new DataSetConfig
        {
            Id = "dataset",
            MaxSampleCount = 2_000_000,
            Columns =
            [
                new DataSetColumnConfig { Id = "x" },
                new DataSetColumnConfig { Id = "y" },
            ],
        },
    ],
    Series =
    [
        new LineSeriesConfig
        {
            Id = "series-1",
            DataSetId = "dataset",
            X = "x",
            Y = "y",
            Name = "Series 1",
            Color = "#FFD400",
        },
    ],
});
```

### After chart creation

Configure series on an existing chart after defining their datasets.

Add a new series by providing a new ID.

The example below adds a scatter series using the same dataset as in the example above.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

```csharp
chart.ConfigureSeries(
[
    new ScatterSeriesConfig
    {
        Id = "series-2",
        DataSetId = "dataset",
        X = "x",
        Y = "y",
        Name = "Series 2",
        Color = "#6ACBFF",
    },
]);
```

## Series name and color

The series name identifies it in the legend and cursor information. It is separate from the series ID, which identifies the series in configuration updates.

Specify a hexadecimal color to choose the series color. Omit it when creating the series to use the automatically assigned color.

## Assigning axes

Series use the default X and Y axes when their axis IDs are omitted.

To use a specific axis, provide the ID assigned when creating that axis. Default axes with assigned IDs can be selected in the same way as additional axes.

The example below assumes an existing Y axis whose assigned ID is `additional-y`.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

Set `XAxisId` or `YAxisId` in the series configuration. For example:

```csharp
new LineSeriesConfig
{
    Id = "series-1",
    DataSetId = "dataset",
    X = "x",
    Y = "y",
    YAxisId = "additional-y",
}
```

The omitted X-axis ID selects the default X axis.

## Updating series

Configure a series again with the same ID to change its name, color, dataset, column bindings, or selected axes. Choose a different configuration class to change between a line, scatter points, and a line with points.

Supply the required dataset and column bindings again, and retain any axis IDs needed by the series. Series omitted from the call remain unchanged.

The example below updates the name and color of the series configured in the preceding section. Required dataset and column bindings are supplied again.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

```csharp
chart.ConfigureSeries(
[
    new LineSeriesConfig
    {
        Id = "series-1",
        DataSetId = "dataset",
        X = "x",
        Y = "y",
        YAxisId = "additional-y",
        Name = "Updated series",
        Color = "#6ACBFF",
    },
]);
```

## Updating data

Use dataset operations to replace historical data or append incoming samples. Series bound to that dataset display the updated data without requiring another series configuration call.

See [Data management](./data-management).
