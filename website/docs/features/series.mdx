A series determines how data is displayed in a chart. Each series requires an ID that is unique within the chart.


## Series types

Choose the configuration class for the visualization you need:
- [`LineSeriesConfig`](./series#line-scatter-line-scatter) displays a line.
- [`ScatterSeriesConfig`](./series#line-scatter-line-scatter) displays scatter points.
- [`LineScatterSeriesConfig`](./series#line-scatter-line-scatter) displays a line with scatter points.

The configuration class determines the series type. A series's ID, type, and assigned axes cannot be changed after creation.


## Adding series

Add series when creating a chart through its series list. To add a series afterward, include its creation configuration with a new unique ID in a chart update.
A new series can reference datasets and axes created in the same chart configuration or update. Adding a series does not remove existing series.

Omitted series and properties remain unchanged during updates. Removal must be requested explicitly.

The examples continue [Adding charts](./charts), using the chart reference introduced there.

### Line, Scatter, Line-Scatter

#### At chart creation

Add series to the chart's series list. Define their datasets in the same chart configuration or create the datasets beforehand.

Line, scatter, and line with scatter points series select dataset columns for their X and Y values. Multiple series can share the same dataset and columns.

The example below creates a dataset containing time, three temperature measurements, and humidity. A line series displays `"temperature-1"` and a scatter series displays `"temperature-2"`, both against `"time"` using the default axes.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

```csharp
_chart = await _context.CreateChartAsync(new XYChartConfig
{
    ContainerId = "signal-chart",
    DataSets =
    [
        new DataSetConfig
        {
            Id = "measurements",
            MaxSampleCount = 1_000_000,
            Columns =
            [
                new DataSetColumnConfig { Id = "time" },
                new DataSetColumnConfig { Id = "temperature-1" },
                new DataSetColumnConfig { Id = "temperature-2" },
                new DataSetColumnConfig { Id = "temperature-3" },
                new DataSetColumnConfig { Id = "humidity" },
            ],
        },
    ],
    Series =
    [
        new LineSeriesConfig
        {
            Id = "series-1",
            DataSetId = "measurements",
            X = "time",
            Y = "temperature-1",
            Name = "Temperature 1",
            Color = "#FFD400",
        },
        new ScatterSeriesConfig
        {
            Id = "series-2",
            DataSetId = "measurements",
            X = "time",
            Y = "temperature-2",
            Name = "Temperature 2",
            Color = "#6ACBFF",
        },
    ],
});
```

#### After chart creation

To add a series to an existing chart, include its creation configuration with a new unique ID in a chart update.

The following adds a line with scatter points using the same dataset. It shares the `"time"` column with the existing series and selects `"temperature-3"` for its Y values. All three series use the default axes.

```csharp
    Series =

            Y = "temperature-3",
```

## Series name and color

The series name identifies it in the legend and cursor information. It is separate from the ID used to select the series in updates.

Specify a hexadecimal color to choose the series color. Omit it when creating the series to use the automatically assigned color.

Names and colors can be changed after creation. Omitting either property from an update preserves its existing value. An empty name clears the displayed name.


## Assigning axes

Series use the default X and Y axes when their axis IDs are omitted.

To select another axis, supply the ID assigned to that axis. Default axes with assigned IDs can be selected in the same way as additional axes.

First, add the Y axis shown in [Adding axes after creation](./axes#adding-axes-after-creation). Its example ID is `"additional-y"`. 
The following adds a line series displaying humidity against time. It selects that additional Y axis while continuing to use the default X axis.

<TabItem value="blazor" label="Blazor">


## Updating series

Use an update configuration matching the existing series type:

- [`UpdateLineSeriesConfig`](./series#line-scatter-line-scatter-1) updates a line series.
- [`UpdateScatterSeriesConfig`](./series#line-scatter-line-scatter-1) updates a scatter series.
- [`UpdateLineScatterSeriesConfig`](./series#line-scatter-line-scatter-1) updates a line with scatter points.

Select the series by its ID and supply the properties to change. Its name, color, dataset ID, and X/Y column bindings are editable. Omitted properties and series remain unchanged.

A series's ID, type, and assigned axes cannot be changed after creation. To use another series type or different axes, remove the old series and create a new one.

The following example changes the name and color of the first line series. Its dataset, column bindings, and assigned axes remain unchanged.

## Removing series

Remove a series through an update configuration matching its type. Only its ID and the removal flag are needed.

The example below removes the scatter series added earlier.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

```csharp
_chart.Update(new UpdateXYChartConfig
{
    Series =
    [
        new UpdateScatterSeriesConfig
        {
            Id = "series-2",
            Remove = true,
        },
    ],
});
```

## Updating data

### Dataset data

Use dataset operations to replace historical data or append incoming samples. Series bound to that dataset display the updated data without requiring another series configuration call. See [Data management](./data-management).
