LightningChart LA creates interactive XY charts with panning and zooming enabled by default. Use your application's normal layout components to position and size each chart.


## Creating a chart

Set the chart title, legend visibility, and animation settings when creating a chart. You can also supply datasets, axes, and series in the initial configuration.
See [Data management](./data-management), [Adding series](./series), and [Configuring axes](./axes) for complete configuration examples.

The examples throughout the Features guides build on the chart created here.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

Render a chart container in your component:

```html
<div id="signal-chart" style="height: 480px"></div>
```

The following continues the example from [Creating a context](./context). It creates a chart after the container has rendered and the context has been initialized:

```csharp
private LclaChart? _chart;

protected override async Task OnAfterRenderAsync(bool firstRender)
{
    if (!firstRender) return;

    var license = new LclaLicense
    {
        Key = Configuration["LCJS_LICENSE_KEY"]!,
    };

    _context = new LclaContext(new BlazorTransport(JSRuntime), license);

    _chart = await _context.CreateChartAsync(new XYChartConfig
    {
        ContainerId = "signal-chart",
        Title = "Signal chart",
    });
}
```

Set these properties in `XYChartConfig`:

- **`ContainerId`** — The ID of the existing HTML element containing the chart. Size and position that element using your application's layout. The container cannot be changed after chart creation.
- **`Title`** — The title displayed above the plotting area. Omit it to use the default title, or set `Title = ""` to hide it.
- **`LegendVisible`** — Show or hide the chart legend, including any LUT color scales. The legend is visible by default; set `LegendVisible = false` to hide it.
- **`AnimationsEnabled`** — Enable or disable chart animations. Animations are enabled by default; set `AnimationsEnabled = false` to disable them. This setting cannot be changed after chart creation.
- **`DataSets`** — Create datasets containing named data columns. See [Data management](./data-management).
- **`Axes`** — Configure the default axes and create additional axes. Omit the list to use the normal default X and Y axes. See [Configuring axes](./axes).
- **`Series`** — Create the series that display your data. See [Adding series](./series).

Add the Flutter widgets import alongside the existing client-library import:

```dart
import 'package:flutter/widgets.dart';
```

Below the license declaration, add this widget:

```dart
class SignalChart extends StatefulWidget {
  const SignalChart({super.key});

  @override
  State<SignalChart> createState() => _SignalChartState();
}

class _SignalChartState extends State<SignalChart> {
  LightningChartController? _chart;

  @override
  Widget build(BuildContext context) {
    return SizedBox(
      height: 480,
      child: LightningChart.xy(
        license: license,
        title: 'Signal chart',
        onChartCreated: (chart) {
          _chart = chart;
        },
      ),
    );
  }
}
```

Place `const SignalChart()` in your application's widget tree. `onChartCreated` receives the controller when the chart is ready.
The example stores it in `_chart` so other methods in `_SignalChartState` can update the chart or supply data.

Set these parameters in `LightningChart.xy`:

- **`title`** — The title displayed above the plotting area. Omit it to use the default title, or set `title: ''` to hide it.
- **`legendVisible`** — Show or hide the chart legend, including any LUT color scales. The legend is visible by default; set `legendVisible: false` to hide it.
- **`animationsEnabled`** — Enable or disable chart animations. Animations are enabled by default; set `animationsEnabled: false` to disable them. This setting cannot be changed after chart creation.
- **`dataSets`** — Create datasets containing named data columns. See [Data management](./data-management).
- **`axes`** — Configure the default axes and create additional axes. Omit the list to use the normal default X and Y axes. See [Configuring axes](./axes).
- **`series`** — Create the visualizations that display your data. See [Adding series](./series).
- **`initialData`** — Supply dataset data to load when the chart is ready. See [Data management](./data-management).

## Updating a chart

Use an update configuration to change the chart title, legend visibility, or configure datasets, axes, and series after creation. Omitted objects and properties remain unchanged.
The chart's container and animation setting cannot be changed after creation.

The following changes the chart title and hides the legend:

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

```csharp
_chart.Update(new UpdateXYChartConfig
{
    Title = "Updated signal chart",
    LegendVisible = false,
});
```

</TabItem>

## Removing a chart

Release the chart when its view is no longer needed.

<Tabs groupId="lcla-client" defaultValue="blazor">
<TabItem value="blazor" label="Blazor">

```csharp
if (_chart is not null)
    await _chart.DisposeAsync();
```

Call this from your component's cleanup code.

Removing a chart leaves other charts and shared datasets in the same context available. Disposing a context releases all charts it owns.

</TabItem>
<TabItem value="maui" label="MAUI">

To remove an individual chart, use the following inside an asynchronous page method:

```csharp
if (_chart is not null)
{
    await _chart.DisposeAsync();
    _chart = null;
}
```

The context cleanup shown on the Context page releases all remaining charts when the page unloads.

Removing a chart leaves other charts and shared datasets in the same context available. Disposing a context releases all charts it owns.
